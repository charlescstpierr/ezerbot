# ADR

Décisions d'architecture de ce dépôt, en contexte unique. Les fichiers se nomment `0001-slug.md`, `0002-slug.md`, et ainsi de suite.

Un ADR peut tenir en un paragraphe : le contexte, ce qui a été décidé, et pourquoi. N'en écrire un que si la décision est difficile à revenir en arrière, surprenante sans ce contexte, et issue d'un vrai arbitrage.
